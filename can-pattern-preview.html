CAN Background Pattern

This page shows the standard Creator Access Network background: the teal-on-gray icon pattern tile with white content cards on top. This is exactly how site sections should look.

Usage specs

PropertyValue
Tile assetcan-pattern-teal-on-gray.svg (960×960 @2x)
Display sizebackground-size: 480px 480px; background-repeat: repeat;
Icon colorDeep Sea Dive #2A6478 at 25% opacity, ~1px stroke at display size
Ground colorCool Gray Blue #F0F4F8 (baked into the tile)
Content on patternAlways inside a white card: #FFFFFF, 4px radius, shadow 0 1px 3px rgba(0,0,0,0.04)

CSS snippet

background: #F0F4F8 url('https://creatoraccessnetwork.github.io/can-widget/can-pattern-teal-on-gray.svg') repeat; background-size: 480px 480px;
